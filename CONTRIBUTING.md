# Contributing

Thank you for your interest. This repository does not accept pull requests: the catalog reaches the
Gallery only in releases we sign ourselves. Instead:

- found a bug in a template, or a shortcut that changed in a new version of an app — write to
  support@desmaptic.com with the template, the app's version and what happens;
- a script that can do harm — see [SECURITY.md](SECURITY.md) and report it privately;
- want a widget or an app page that is not here — write to support@desmaptic.com and describe what
  you would like to see on the button and what a tap should do.

Your own widgets work without us: build them in the app or with an AI assistant (see the
[README](README.md)), using the scripts here as examples under the catalog's [license](LICENSE).
